## ⚠️ Sheet ID ถูกปิดไว้ — repo นี้เป็น public

repo นี้เปิดสาธารณะ เอกสารต้นฉบับมี **ID ของ Google Sheet ที่เก็บยอดขายจริง**
จึงแทนที่ด้วย placeholder ก่อนขึ้น git · **เนื้อหาอื่นคงเดิมทุกตัวอักษร**

| placeholder | คือชีตอะไร |
|---|---|
| `<SHEET_ID_SS>` | ศรีสมาน |
| `<SHEET_ID_BG>` | ประตูกรุงเทพ |
| `<SHEET_ID_BN>` | บางนา |
| `<SHEET_ID_WALKIN_EXTERNAL>` | ชีตภายนอกของระบบวอล์กอิน (`EXTERNAL_SS_ID`) |
| `<SHEET_ID_PENALTY_RULES>` | ตารางกฎหักคะแนน/งดรับจอง |

**ค่าจริงหาได้จาก 2 ที่:**
1. โฟลเดอร์เดิมในเครื่อง `Web-SG-DB/SaveOneGo-v2.11.1/` (ยังอยู่ครบ ไม่ได้ลบ)
2. ตัว Apps Script ของแต่ละสาขา (`SHEET_ID` ด้านบนสุดของไฟล์)

> 🔴 **อย่าเติมค่าจริงกลับลงไฟล์เหล่านี้แล้ว commit** — ขึ้น git แล้วลบไม่ได้ ค้างใน history ถาวร
> ถ้าจำเป็นต้องใช้ค่าจริงในเครื่อง ให้ก๊อปไฟล์ออกไปแก้ข้างนอก repo
