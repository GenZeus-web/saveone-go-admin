# แอปกรอกเลขไมล์ น้ำ-ไฟ (UTIL-02)

Apps Script Web App ที่**ผูกกับชีตกลาง UTIL** · พนักงานเปิดลิงก์บนมือถือ ใส่**รหัสสาขา + รหัสพนักงาน 6 หลัก** → เลือกมิเตอร์ → ถ่ายรูปหน้าปัด (ไม่บังคับ) → ใส่เลขไมล์ → บันทึก
แอป**ไม่คำนวณ** · การคำนวณทั้งหมดอยู่เว็บ (`js/util-calc.js`) · สัญญาข้อมูล `docs/util-data-contract.md`

| ไฟล์ | วางที่ไหนใน Apps Script |
|---|---|
| `Code.gs` | ไฟล์สคริปต์ `Code.gs` |
| `Index.html` | ไฟล์ HTML ชื่อ `Index` (สร้างด้วย ＋ → HTML) |
| `appsscript.json` | Project Settings → ติ๊ก "Show appsscript.json" แล้ววางทับ |

## ติดตั้งครั้งแรก

1. เปิดชีตกลาง → **ส่วนขยาย → Apps Script**
2. วาง 3 ไฟล์ตามตารางข้างบน → บันทึก
3. เลือกฟังก์ชัน **`setup`** → ▶ Run → อนุญาตสิทธิ์ (Sheets · Drive · เชื่อมต่อภายนอก · Firestore) · **รันซ้ำทุกครั้งที่อัปเดตโค้ด** (ไม่สร้างของซ้ำ)
   - เพิ่มคอลัมน์ `photo_id` `staff_id` ในแท็บ `readings` + สร้างแท็บ **`staff`** ให้เอง
   - หาโฟลเดอร์ `UTIL รูปมิเตอร์` ข้างชีต (ไม่มี = สร้าง)
   - Log บอกว่าใครเข้าแอปได้บ้าง · รหัสซ้ำ/ขาด `staff_id` · ตอนนี้บังคับถ่ายรูปไหม
4. ใส่รายชื่อในแท็บ **`staff`** (1 แถว = 1 คนต่อ 1 สาขา) · ซ่อนแท็บ + Protect range
   | staff_id | name | branch_code | emp_code | active |
   |---|---|---|---|---|
   | BN01 | ช่างเอ | BN | รหัสพนักงาน 6 หลัก | TRUE |
   `staff_id` = รหัสสั้นที่บันทึกลงชีต/เว็บ · `emp_code` = รหัสเข้าแอป **อยู่ในชีตนี้ที่เดียว**
   `branch_code` = `*` → เข้าได้ทุกสาขาที่เปิดอยู่ (admin/เจ้าของ) · รหัสห้ามซ้ำกับคนในสาขาใดๆ
5. ⏰ ทริกเกอร์ → **+ เพิ่มทริกเกอร์** → `pushToFirestore` / Head / ตามเวลา / นาที / **ทุก 10 นาที**
   ทดสอบก่อน: ▶ `pushToFirestore` → Log ต้องขึ้น `เขียน N เอกสาร · พลาด 0`
6. **Deploy → New deployment → Web app**
   - Execute as: **Me** · Who has access: **Anyone**
   - ได้ลิงก์ `.../exec` → ส่งให้สาขา (เปิดบนมือถือ / เพิ่มลงหน้าจอหลัก)
7. แก้โค้ดครั้งหน้า: **Deploy → Manage deployments → ✏️ → Version: New version** (ลิงก์เดิมไม่เปลี่ยน)

## เพิ่มสาขาใหม่ (เช่น สาขาราม)

สาขาราม: รหัส **`RM`** (ชั่วคราว 13 ต.ค. 2569 · เปิดสิ้นปี) · โฟลเดอร์รูป `UTIL รูปมิเตอร์/RM` สร้างรอไว้แล้ว

ไม่ต้องแก้โค้ด — แก้แค่ชีต:
1. แท็บ `branches` เพิ่มแถว: รหัสสาขา · ชื่อ · รหัสฝั่งบัญชี · (ช่อง pin ไม่ใช้แล้ว) · `TRUE`
2. แท็บ `meters` เพิ่มมิเตอร์ของสาขา (`meter_id` = `รหัสสาขา-W/E-จุด`)
3. แท็บ `staff` เพิ่มพนักงานของสาขา
4. รูปจะไปอยู่ `UTIL รูปมิเตอร์/<รหัสสาขา>/<ปี-เดือน>/` เอง

ยังไม่เปิด = ใส่ `active` เป็น `FALSE` ไว้ก่อน (ทุกคนในสาขาเข้าไม่ได้จนกว่าจะเป็น `TRUE`)
ฝั่งเว็บยังต้องเพิ่มรหัสสาขาใหม่ในตัวเลือกสาขา + `branches` ของผู้ใช้ (งานแยก)

## กติกาที่แอปบังคับ

| เรื่อง | ผล |
|---|---|
| เข้าแอป | รหัสสาขา + รหัสพนักงาน 6 หลัก ต้องเป็นคนของสาขานั้น · ใช้รหัสตัวเองเข้าสาขาอื่นไม่ได้ · เครื่องจำรหัสสาขาไว้ |
| รหัสผิด 5 ครั้งใน 15 นาที | ล็อก**เฉพาะสาขานั้น** 15 นาที (สาขาอื่นยังเข้าได้) |
| คนจด | ระบบใส่ชื่อ + `staff_id` จากคนที่เข้าแอป (พิมพ์ชื่อเองไม่ได้) |
| ยกเลิกรายการ | เฉพาะของตัวเอง ที่มิเตอร์นั้น**ยังไม่มีการจดครั้งถัดไป** → แถวเป็น `void` + หมายเหตุ "ยกเลิกโดย…" (ไม่ลบแถว) · เกินนั้น admin แก้ในชีต |
| ป้ายรอบจด | ✅ จดรอบนี้แล้ว · ⏰ ถึงรอบ · ⚠️ เลยรอบ · **น้ำ** = ทุกวัน เวลารอบ = แท็บ `branches` ช่อง `rounds` (ว่าง = `14:00` · ใส่หลายรอบได้ `14:00,01:00`) · **ไฟ** = ทุกวันจันทร์ เวลารอบแรก (`ELEC_WEEKDAY`) จดแล้ว = ✅ ทั้งสัปดาห์ · จดได้ก่อน/หลังรอบ 1 ชม. |
| บทบาท (`staff.role`) | ว่าง = จดมิเตอร์ · `acct` = บัญชี กรอกบิลอย่างเดียว · `admin` = ทั้งสองอย่าง (มีแท็บสลับ) |
| กรอกบิล | ต่อท้ายแท็บ `bills` + `entered_by`/`entered_at` · บิลเดือนเดิมของมิเตอร์เดิมซ้ำ = ปฏิเสธ · หน่วย+เงินเท่าเดือนก่อนทุกหลัก = ต้องกดยืนยัน |
| ยกเลิกบิล | บิลที่กรอกผ่านแอป: ของตัวเอง (admin = ของใครก็ได้) → `status = void` + หมายเหตุ "ยกเลิกโดย…" แล้วกรอกเดือนเดิมใหม่ได้ · ไม่ส่งขึ้นเว็บ · แถวเก่าจาก Excel = admin แก้ในชีต · **ต้องรัน ▶ setup ก่อน** (เพิ่มคอลัมน์ `status` ในแท็บ bills) |
| log ในแอป | จดล่าสุดของสาขา 10 รายการ + ประวัติต่อมิเตอร์ · ที่ยกเลิกแล้วขีดฆ่า |
| ไม่ถ่ายรูป | **บันทึกได้** (ค่าตั้งต้น · รอ ผอ. ตัดสิน) · บังคับ = Project Settings → Script properties → `PHOTO_REQUIRED` = `TRUE` มีผลทันที ไม่ต้อง deploy ใหม่ |
| เลขน้อยกว่าครั้งก่อน | ปฏิเสธ · เว้นติ๊ก "เปลี่ยนมิเตอร์ใหม่" + ใส่หมายเหตุ |
| เวลาที่บันทึก | เวลา server (`ts`) ไม่ใช่เวลามือถือ · เวลาบนรูปเป็นเวลามือถือ ไว้ให้คนดู |
| จดย้อนหลัง | **ไม่รองรับ** — ลืมจดให้ admin เพิ่มแถวในชีตเอง (`source = paper` · `ts` ว่าง) |
| เข้าแอปครั้งเดียว | ใช้ได้ 6 ชม. แล้วต้องเข้าใหม่ |

รูป: ย่อในมือถือ (ด้านยาว ≤ 1600px ≈ 200–400 KB) + พิมพ์รหัสมิเตอร์/เวลาลงรูป
ชื่อไฟล์ `<meter_id>_<ปีเดือนวัน-เวลา>.jpg` · `photo_id` ในชีต = ID ไฟล์ใน Drive
เปิดดูรูป: `https://drive.google.com/file/d/<photo_id>/view` (เห็นได้เฉพาะคนที่มีสิทธิ์โฟลเดอร์)

## ทดสอบหลังติดตั้ง

1. รหัสผิด → "ไม่ถูกต้อง" · ผิดครบ 5 → "สาขานี้ลองใหม่อีก 15 นาที" · ใช้รหัสคนสาขาอื่น → เข้าไม่ได้
2. รหัสถูก → เห็นเฉพาะมิเตอร์ของสาขานั้น + เลขครั้งก่อน (บางนา: ห้องน้ำ 7791 · สำนักงาน 1188)
3. ใส่เลขน้อยกว่าครั้งก่อน → ถูกปฏิเสธ
4. บันทึกจริง 1 ครั้ง → แท็บ `readings` มีแถวใหม่ `source = app` + มีรูปในโฟลเดอร์สาขา
5. กด "ยกเลิก" ที่รายการทดสอบใน log → แถวเป็น `void` + หมายเหตุ "ยกเลิกโดย…"
6. ▶ `pushToFirestore` → Firestore มี `data/BN_UTIL` (`utilbill/*` เว็บอ่านไม่ได้จนกว่าจะเปิด Rules)
